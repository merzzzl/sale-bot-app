# Frontend

UI for the Telegram Mini App as part of **sale-bot-app**.

## Tech stack

- TypeScript + React (Vite)
- Chakra UI (including charts)
- Telegram Mini Apps SDK
- TanStack React Query, React Router
- i18next (localization), Axios (HTTP)
